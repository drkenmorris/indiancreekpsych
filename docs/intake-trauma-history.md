No removed status options are restored, and no additional EMR note fields are copied. Nothing is selected by default; all groups may remain unanswered.

Empty string means unanswered. Client/private database validation checks exact version, top-level shape, known groups and string choices, duplicates and a 12000-character bound. Existing patient ownership/version checks, kiosk token expiry/stale checks, staff role/MFA review and submitted locks remain. Legal statement revision and signatures are unchanged by this non-legal page edit. No new tables, grants or storage services. No EMR changes and no intake-to-EMR transfer testing: the owner has deferred transfer testing until clinical production work.
